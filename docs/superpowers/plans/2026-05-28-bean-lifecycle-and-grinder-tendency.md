# Bean Lifecycle And Grinder Tendency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a normal "finished bag" lifecycle with finished-date statistics, keep archive/discard as exceptional, and make bean detail/list grinder and inventory signals always visible and safer.

**Architecture:** Keep lifecycle state derived from bean fields in `Bean`, with `finished_at` as the normal endpoint and `archived_at` as exceptional removal. Keep grinder suggestions anchored on the current bag's first brew, use `BeanStatistics` for bean-scoped distributions and finished stats, and render all UI server-side through existing Rails/Hotwire views.

**Tech Stack:** Rails 8.1, Active Record migrations, ERB views, Tailwind utility classes, Minitest integration/model/service tests, PostgreSQL.

Migration:

```ruby
class AddFinishedAtToBeans < ActiveRecord::Migration[8.1]
  def change
    add_column :beans, :finished_at, :datetime
    add_index :beans, [ :workspace_id, :finished_at ]
  end
end
```

Model changes:

```ruby
BAG_STATUSES = %w[stock open used_up finished archived].freeze
LOW_REMAINING_GRAMS = BigDecimal("18")

scope :open, -> {
  where(archived_at: nil, finished_at: nil)
    .where.not(opened_on: nil)
    .where("remaining_grams > 0")
    .order(Arel.sql("opened_on ASC NULLS LAST"), :created_at)
}

def finished?
  bag_status == "finished"
end

def bag_status
  return "archived" if archived_at.present?
  return "finished" if finished_at.present?
  return "used_up" if remaining_grams.present? && remaining_grams <= 0
  return "open" if opened_on.present?

  "stock"
end

def finish!
  update!(finished_at: Time.current, archived_at: nil, opened_on: opened_on || Date.current)
end

def reopen!
  self.archived_at = nil
  self.finished_at = nil
  self.opened_on ||= Date.current
  self.remaining_grams = bag_size_grams if remaining_grams.to_d <= 0
  save!
end
```

Add `finished_used_grams`, `finished_open_days`, `finished_grams_per_day`, `nearly_finished?`, and `remaining_percent` helpers. Update `apply_bag_status` so `stock` and `open` clear `finished_at`, `finished` calls normal finished state, `used_up` clears `finished_at`, and `archived` clears `finished_at`.
