# Brew Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the plain brew detail layout with a compact screenshot-worthy Hero Brew Card.

**Architecture:** Keep the feature server-rendered in Rails. Add a small helper for card formatting and chart labels, then update `app/views/brews/show.html.erb` to render the dense card from current brew data and brew preparation tool snapshots.

**Tech Stack:** Rails 8.1, ERB, Minitest, inline SVG, Tailwind utility classes plus small scoped CSS in the template.
